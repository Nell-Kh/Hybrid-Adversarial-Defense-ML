# Hybrid Adversarial Defense System

A research-grade framework for evaluating the robustness of Deep Learning models (ResNet-18) against advanced adversarial attacks. This project implements a complete "Offense vs. Defense" pipeline on the Tiny-ImageNet dataset.

## 🚀 Project Overview

The goal of this system is to study the vulnerability of Computer Vision models by:
1.  **Breaking them** with state-of-the-art attacks (White-Box & Black-Box).
2.  **Defending them** with advanced training and detection mechanisms.

We use **ResNet-18** as our baseline model and **Tiny-ImageNet** (200 classes) as the benchmark dataset.

---

## ⚔️ The Attack Suite (Offense)

We have implemented a modular arsenal of attacks, currently achieving a **100% success rate** against the standard ResNet-18 model.

### 1. AutoAttack (White-Box)
*   **Type**: Mathematical / Gradient-based
*   **Mechanism**: Uses an ensemble of PGD (Projected Gradient Descent) with Cross-Entropy and DLR loss functions.
*   **Impact**: Finds the most potent invisible noise to trick the model. It is the current gold standard in robustness benchmarking.

### 2. DeepFool (White-Box)
*   **Type**: Geometric / Minimum-Norm
*   **Mechanism**: Visualizes the decision boundary as a hyperplane and computes the shortest mathematical path to cross it.
*   **Impact**: Generates the *smallest possible* perturbation (least visible noise) to cause misclassification.

### 3. Boundary Attack (Black-Box)
*   **Type**: Decision-based / Gradient-Free
*   **Mechanism**: Starts with a large perturbation (an image of a different class) and performs a "random walk" along the decision boundary to minimize distance to the target image.
*   **Impact**: Can break models even without access to their code or gradients (e.g., attacking a remote API).

### 4. Adversarial Patch (Physical)
*   **Type**: Physical / Universal
*   **Mechanism**: A generated "sticker" trained with Expectation Over Transformation (EOT).
*   **Impact**: When placed anywhere on an image, it forces the model to ignore the main subject and classify the image as a target class (e.g., "Goldfish").

---

## 🛡️ The Defense Suite (Planned)

To counter these attacks, we are developing a multi-layered defense system:

### 1. Adversarial Training
*   **Concept**: "Vaccinating" the model by training it on the very adversarial examples generated by our attack suite.
*   **Goal**: Force the model to learn robust features that are invariant to small noise.

### 2. Mahalanobis Detection
*   **Concept**: Statistical anomaly detection.
*   **Mechanism**: Modeling the distribution of actications in the deep layers of the network. Adversarial examples often lie in low-probability regions of this latent space.
*   **Goal**: Flag and reject malicious inputs before they reach the classifier.

## 💻 Usage

### Installation
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Running the Benchmark
Test the complete Attack Suite against the model:
```bash
python3 src/evaluate_suite.py
```
**Options:**
*   `--attacks all`: Run AutoAttack, DeepFool, and Boundary.
*   `--batch-size 32`: Set number of test images.

### Visualizing Results
Generate a "Trophy Case" gallery comparing all attacks on a single image:
```bash
python3 src/visualize_all.py
```
*Output saved to `data/viz_results/attack_gallery.png`*
